# Calculadora Seguro UK

Estimador indicativo, non-underwritten, calibrado com illustrations históricos anonimizados.

- 1.029 PDFs auditados no acervo
- 184 arquivos candidatos a illustration/cotação
- 181 documentos únicos extraídos
- 161 registros completos e aprovados para testes por família
- 43 registros comparáveis no modelo publicado de Vida + CI Standard/Core
- erro mediano fora da amostra: 10,2%

Os valores não constituem cotação ou garantia de aceitação. Confirme sempre o resultado final no SolutionBuilder e com a seguradora.

Os dados preenchidos não são enviados a servidor. As simulações salvas ficam no `localStorage` do navegador utilizado.
